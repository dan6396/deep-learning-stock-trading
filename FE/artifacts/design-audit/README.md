# 웹 디자인 검사 — 2026-10-09

아래는 개선 전 검사 기록입니다. 세 발견 사항은 후속 작업으로 모두 개선했으며 [개선 결과와 재검증](../design-improvements/README.md)에 현재 상태를 기록했습니다.

검사 대상은 새 웹의 브리핑, 전체 순위, 관심, 분석 기록, 종목 리포트, 서비스 소개입니다. `ui-ux-pro-max`의 웹에 해당하는 가독성·반응형·포커스 기준과 `design`의 시각적 위계·토큰 일관성 기준을 적용했습니다. 앱 전용 pt/dp 규칙을 웹의 필수 기준으로 적용하지 않았습니다.

## 발견 사항

### 1. 높음 — 안내 영역이 주요 작업과 결과보다 먼저 화면을 차지함

- 첫 방문 상태의 375×812 화면에서 분석 시작 버튼 상단은 문서의 약 897px, 최종 후보 제목은 약 1698px에 있습니다. 버튼과 핵심 결과가 첫 화면에 보이지 않습니다.
- 1440×1000 화면에서도 후보 제목은 약 1099px로 첫 화면 아래에 있습니다.
- 공통 연결 상태 카드가 모든 화면의 제목보다 먼저 나오며, 정상 상태에서도 데스크톱에서 약 179px를 차지합니다. 브리핑은 첫 방문 안내·날짜·분석 실행 카드·시장 지수가 추가로 쌓입니다.
- 근거: `src/app/AppShell.tsx:34`, `src/features/briefing/BriefingPage.tsx:48`, `src/features/connection/connection.css:2`.
- 개선: 정상 연결 상태를 한 줄로 줄이고 세부 설명은 접습니다. 오류는 펼쳐서 보여줍니다. 분석 시작은 제목 근처에 놓고, 후보 비교를 시장 지수보다 먼저 배치하거나 지수를 모바일에서 요약합니다. 날짜·출처는 관련 결과 가까이에 유지합니다.
- 증거: [모바일 브리핑 전체](briefing-375-light-full.png), [데스크톱 브리핑](briefing-1440-dark.png).

### 2. 중간 — 모바일 순위 표를 가로로 이동하면 종목 식별 정보를 잃음

- 375px 화면에서 표의 표시 폭은 311px, 콘텐츠 폭은 1120px입니다. 가로 450px 이동 시 모델 예측은 보이지만 종목명 영역은 화면 왼쪽 밖으로 완전히 사라집니다.
- 가로 이동 안내는 접근성 이름에 있으나 시각적으로 보이는 안내는 없습니다. 가로 스크롤 자체는 접근성 위반으로 판정하지 않았습니다.
- 근거: `src/features/rank/rank.css:19`, `src/features/rank/rank.css:20`, `src/features/rank/RankTable.tsx:26`.
- 개선: 모바일에서 종목·원본 순위·모델 예측을 먼저 보여주고 추가 근거는 펼치게 합니다. 표를 유지한다면 첫 열 고정과 보이는 가로 이동 안내를 함께 제공합니다.
- 증거: [가로 이동한 모바일 순위 표](rank-375-dark-scrolled.png), [측정값](interactions.json).

### 3. 중간 — 중요 출처·기준 시각·해석 안내가 10px로 표시됨

- 출처, 저장 시각, 지수 시계열 유형, 예측 해석 안내에 실제 계산된 글자 크기 10px가 사용됩니다. 대비 검사에는 통과하지만 모바일에서 읽기 어렵습니다.
- 이 항목은 글자 크기에 대한 사용성 판단이며, 최소 글자 크기 관련 WCAG 실패로 분류하지 않았습니다.
- 근거: `src/features/briefing/briefing.css:46`, `src/features/briefing/briefing.css:57`, `src/features/briefing/briefing.css:80`.
- 개선: 데이터 해석에 필요한 메타정보는 12–13px, 일반 본문은 14px 이상을 목표로 합니다. 글자를 줄이는 대신 중복 안내를 정리하고 상세 설명을 접습니다.
- 증거: [실제 계산된 글자 크기](audit.json).

## 검증 결과와 범위

- 최신 코드로 `npm run build` 통과.
- 6개 화면 × 1440×1000 / 375×812 / 667×375 × 다크 / 라이트 = 36개 조합 확인.
- axe-core의 WCAG A/AA 관련 자동 검사 위반 0건. 이 결과는 전체 WCAG 준수 인증을 뜻하지 않습니다.
- 페이지 단위 가로 넘침 0건. 표 내부 가로 스크롤은 별도로 평가했습니다.
- 검사한 표시 컨트롤에서 24px 미만 크기 0건. 간격 예외까지 포함한 수동 타깃 크기 적합성 전체 판정은 하지 않았습니다.
- 모바일 브리핑의 Tab 이동 18회에서 표시 포커스 누락·완전 가림 없음.
- 모바일 검색의 입력 포커스, Escape 닫기, 버튼으로 포커스 복귀 확인. 검색 대화상자 자동 접근성 위반 0건.
- 브라우저 console error와 exception 0건.
- 로컬 fixture 자료로 검사했습니다. 실제 시세 조회·Python 분석·유료 호출을 실행하지 않았습니다. 실제 iOS Safari, 화면 읽기 프로그램, 브라우저 200% 확대는 이번 범위에 포함하지 않았습니다.
- 앱 소스는 변경하지 않았으며, 검사 산출물만 이 디렉터리에 저장했습니다.
