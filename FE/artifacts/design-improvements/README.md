# 웹 디자인 개선 결과

2026-10-09 디자인 검사에서 발견한 세 항목을 모두 개선했습니다. 이전 측정과 동일한 로컬 fixture 자료, 375×812 첫 방문 상태로 비교했습니다.

| 항목 | 개선 전 | 개선 후 |
| --- | --- | --- |
| 모바일 분석 시작 버튼 상단 | 897px | 440px |
| 모바일 후보 비교 제목 상단 | 1698px | 684px |
| 정상 연결 상태 카드 높이(1440px) | 179px | 46px |
| 모바일 순위 표 가로 이동 | 종목명 화면 밖으로 사라짐 | 종목 열 고정, 450px 이동 후에도 종목명 표시 |
| 출처·기준 시각·해석 안내 | 10–11px | 12px |

## 변경 내용

- 정상 연결 상태는 접힌 한 줄 요약으로 표시합니다. 상세는 키보드·마우스로 펼칠 수 있으며 조회 실패, 분석 실패, 유효하지 않은 설정·결과는 자동으로 펼칩니다. 설정 존재와 실제 조회 성공은 구분합니다.
- 브리핑의 분석 시작과 최종 후보 비교를 먼저 배치했습니다. 첫 방문 안내와 시장 지수는 후보 아래로 이동했습니다.
- 분석 기준일과 저장 출처·시각은 후보 표 가까이에 항상 표시합니다. 추가 시각·예측 기준은 펼쳐서 확인합니다.
- 순위 표는 종목명 열을 고정하고 보이는 가로 이동 안내를 제공합니다. 원본 순위 다음에 모델 예측을 배치했습니다. 키보드로 정렬 버튼에 이동할 때 고정 열에 포커스가 가려지지 않도록 스크롤을 보정합니다.
- 브리핑·종목 리포트·순위 표의 중요 메타정보와 관련 보조 설명을 12px로 확대했습니다. 검색·분석 기록의 10–11px 보조 글자도 함께 정리했습니다.

## 검증

- `npm test`: 29개 파일, 357개 테스트 통과.
- `npm run build`: TypeScript 검사 및 프로덕션 빌드 통과.
- `node scripts/verify/design-improvements-smoke.mjs`: 6개 화면 × 3개 크기 × 2개 테마, 36개 조합과 218개 검사 통과.
- axe-core의 WCAG A/AA 자동 규칙 위반 0건, 페이지 가로 넘침 0건, 검사한 메타정보 12px 이상.
- 모바일에서 분석 시작 버튼과 후보 제목이 첫 화면 안에 들어옴을 확인했습니다. 후보 행 전체가 첫 화면에 표시된다는 뜻은 아닙니다.
- 가로 스크롤 후 종목명 유지, 정렬 버튼 5개 포커스 표시, 오류 상태 자동 펼침, 수동 펼침·접기, 브리핑 Tab 이동 18회, 검색 포커스·Escape 복귀 확인.
- `node scripts/verify/analysis-control-smoke.mjs`: 분석 요청, 중복 실행 방지, 완료 상태 전환, 뉴스 유료 호출 안내 등 기존 분석 컨트롤 검사 15개 통과.
- 실제 Python 분석·시세 조회·유료 API는 실행하지 않았습니다. 자동 검사는 전체 WCAG 준수 인증을 뜻하지 않습니다. 실제 iOS Safari·화면 읽기 프로그램은 이번 검증에 포함하지 않았습니다.
