# KOSPI200 · 20일·120일 Transformer 앙상블

다음 거래일 시가→종가 수익률이 **상대적으로 나을 종목을 선별**하는 졸업작품입니다. 기본 가격 모델은 **20일·120일 순위 모델의 50:50 단순평균**입니다. 기간별 seed 42·43·44 모델 3개씩, 총 6개 고정 가중치를 사용합니다. 이번 서비스 연결에서 재학습·튜닝하지 않았습니다.

`rank_score`는 같은 날 비교 종목 내 **상대 순위 점수**입니다. 예상수익률(%)·상승확률이 아니며, 부호로 상승·하락을 판단하지 않습니다. 종목 구성에 따라 값이 달라지므로 다른 날짜·모집단의 점수 크기를 직접 비교하지 않습니다.

## 모델과 선정 흐름

1. KOSPI200 후보 전체에서 같은 완료 거래일의 OHLCV와 KOSPI200·KOSPI 지수를 수집합니다.
2. 모든 모델에 공통으로 **최근 120거래일 특징이 유효한 종목**만 남깁니다. 20일 모델도 동일 모집단을 비교합니다.
3. 학습 때 고정한 스케일러를 적용합니다. 11개 종목 특징과 10개 지수 특징을 사용합니다.
4. Time2Vec + Linear 입력 투영 → 2층 Transformer → 마지막 상태/attention pooling → 시장 특징 조건화 → 종목별 점수를 계산합니다. 학습형 게이트와 종목 간 attention은 사용하지 않습니다.
5. 각 seed의 출력을 **당일 종목 간 평균 동순위 → 평균 0·표준편차 1**로 변환합니다. 기간별 3개 seed를 평균한 뒤, 20일과 120일 점수를 50:50으로 평균합니다.
6. 점수 내림차순, 동점이면 종목 코드 순으로 정렬합니다. 기본 Top5에 수급 정보를 첨부하고 관련 RSS 기사를 별도로 표시합니다. 수급·기사는 모델 순위를 변경하지 않습니다.

모델 파일·스케일러와 원본 체크포인트의 SHA-256은 [manifest](models/final_rank_ensemble/manifest.json)에 있습니다. 배포용 `.pt`는 원본 텐서 가중치만 내보냈으며 `weights_only=True`로 로드합니다. 현재 저장소에는 최종 모델 가중치만 포함합니다.

## 학습·검증 범위

| 용도 | 입력 기준일 | 실제 다음 거래일 정답 |
|---|---|---|
| 가중치 학습·스케일러 추정 | 2019-12-20~2024-09-26 | 2019-12-23~2024-09-27 |
| 체크포인트 선택 | 2024-09-30~2024-12-26 | 2024-10-02~2024-12-27 |
| 역사적 개발 비교 | 2024-12-30~2026-09-29 | 2025-01-02~2026-09-30 |

입력 지표 계산 시작일은 2019-06-03입니다. 같은 날짜 구간에서 학습하되 보는 입력 길이가 20일/120일로 다릅니다. 학습 정답은 당일 종목 간 다음날 시가→종가 수익률의 표준화 순위이며 Huber + 0.1 pairwise 손실을 사용했습니다. 추론 시 스케일러를 다시 맞추지 않습니다.

2025·2026은 이미 여러 연구 의사결정에서 관찰한 **개발 자료**로 독립 최종 test가 아닙니다. 과거 구성종목 proxy·수정주가 snapshot 한계가 있습니다. 공급자의 주가 수정과 구성종목 변화 때문에 같은 기준일을 재조회해도 옛 결과와 달라질 수 있습니다. 미래 봉 차단은 원자료가 완전한 시점별 자료임을 보장하지 않습니다. 최종 단순평균 선택은 복잡도와 검증 근거를 함께 고려한 결정이지 모든 기간에서 최고 성능이라는 주장이 아닙니다.

과거 이미지·로그·연구 보고서는 [자료 폴더](materials/README.md)에 모았습니다. 과거 실험의 수치를 현재 최종 모델 성과로 사용하지 않습니다.

## 실행

Python 3.10 이상. 최소 오프라인 추론·검사:

```powershell
python -m pip install -r requirements-inference.txt
python -m unittest discover -s tests -p test_final_rank.py -v
```

서비스 진입점은 그대로입니다. 의존성을 설치하고 로컬 환경에 필요한 설정을 제공한 뒤 실행합니다.

```powershell
python -m pip install -r requirements.txt
python integrated_pipeline.py
cd FE
npm ci
npm run dev -- --host 127.0.0.1
```

웹 기본 `model_only` 모드는 새 모델을 사용합니다. 기본 Top5와 전체 순위, 관련 RSS 기사 흐름을 유지합니다. `PIPELINE_MODEL_MANIFEST`가 설정돼 있으면 기본 경로보다 우선하므로, 옛 경로를 제거하거나 `models/final_rank_ensemble/manifest.json`으로 바꿉니다. GitHub 반영 자체가 실행 중인 호스팅·서버를 재배포하지는 않습니다.

현재 실행 경로는 최종 순위 모델과 관련 RSS 기사 수집입니다. 학습·옛 모델 실행·뉴스 학습형 보정 코드는 포함하지 않습니다.

실행 시 지수 일봉은 `MARKET_INDEX_SOURCE=kis`가 기본입니다. 실전 KIS 구성(`KIS_ENV=real`과 기존 앱 키·시크릿)이 필요하며, 종목 OHLCV는 기존 pykrx 경로를 유지합니다. `MARKET_INDEX_SOURCE=pykrx`로 원래 지수 조회 경로를 선택할 수 있습니다. 해당 경로의 KRX 인증 요건은 설치된 pykrx 버전에 따릅니다.

KIS는 2019-06-03부터 완료일(한국 시각 16시 전에는 전일)까지 코스피200·코스피 일봉을 50행씩 날짜를 후진하며 수집합니다. 요청 간격은 최소 0.6초이고 실패하면 지수 백오프로 최대 3회 시도합니다. `outputs/market_index_history/{KPI200,KOSPI}.csv`를 원자적으로 저장하고 이후 실행은 최근 5거래일을 다시 받아 정정값을 덮어쓰며 증분 수집합니다. 손상된 캐시는 전체 재수집합니다. 최초 실행에는 두 지수 합계 약 74회의 시세 조회가 필요합니다. 원본 수집 출처·시각은 캐시 열과 `latest-request.json`에 남습니다. 두 지수 달력이 다르면 추론을 거부합니다.

지수 거래량은 KIS 원본 단위(지수 거래량, 천 주 추정)이며 모델에서는 20일 평균 대비 비율에만 사용합니다. pykrx 지수 파서와 같이 빈 문자열·`-`는 0으로 해석하고, 명시적 null은 결측으로 남깁니다. 일봉 행을 보간·삭제하지 않으며 기존 모델의 입력 검증을 따릅니다. 종목 피처의 RSI·MACD 초기 상태를 유지하기 위해 이력 시작일을 줄이지 않습니다. Python 인증 구현을 재사용하고 FE의 `.kis-token-cache.json`과 Python 토큰 캐시를 연결해 중복 발급을 줄입니다. 토큰 캐시는 로컬 비밀 파일이므로 공유하거나 커밋하지 않습니다.

최근 5거래일 정정 조회에서 일부 날짜가 누락되면 기존 캐시 행을 보존하고 경고합니다. 응답이 모두 비었거나 달력이 불일치하면 예외로 중단하며 디스크 캐시를 덮어쓰지 않습니다. `tests/test_market_index_history.py`는 로컬 지수 캐시와 모델 scaler가 있을 때 학습 구간 2019-12-20~2024-09-26의 1,174일 시장 피처 10개 평균·표준편차를 소수 5자리로 대조합니다. 파일이 없으면 이 검사만 skip합니다.

FE가 전달한 KIS 환경은 지수 수집기에서 읽기 전용 스냅샷으로 우선 적용합니다. 기존 Python 설정 로더가 루트 로컬 환경으로 덮어쓰는 동작은 다른 단계에서 유지되므로, 수급 단계의 KIS 실전/모의 구성은 별도로 확인해야 합니다.

오프라인 추론은 전체 종목 OHLCV와 두 지수의 동일 달력 자료를 지정합니다. 종목 자료는 Date 인덱스와 Ticker/Open/High/Low/Close/Volume 열, 지수 자료는 Date 인덱스와 Close/Volume 열입니다. 날짜는 시간대 없는 일봉이어야 합니다.

```powershell
python predict.py --data stocks.parquet --kpi200 kpi200.parquet --kospi kospi.parquet --as-of 2026-09-29
```

2019-06-03부터의 가용 이력을 사용해 지수이동평균 지표를 일관되게 계산합니다. 최소 140개 시장 거래일과 유효 종목 30개가 필요합니다. `--ticker 005930`은 전체 모집단으로 계산한 뒤 표시 종목만 제한합니다. 단일 종목만 넣어 같은 점수를 재현할 수 없습니다. 라이브 수집은 KST 16시 이전 당일 봉을 제외하고, 두 지수의 달력 불일치·시장 특징 누락 시 실패합니다.

## 출력·화면 계약

기존 `step2_all_transformer_rank.csv`, `step2_final_top10.csv` 파일명과 화면 경로를 유지합니다.

| 필드 | 새 모델의 의미 |
|---|---|
| `model_id` | `plain_20_120_rank_mean_v1` |
| `score_kind` | `rank_zscore` |
| `rank_score` | 상대 순위 점수, 높은 값 우선 |
| `ensemble_pred_return` | 비움: 수익률로 오인하는 기존 소비자 방지 |
| `prediction_target` | `next_session_open_to_close` (경제적 정답의 대상) |
| `prediction_base_date` | 입력이 끝나는 공통 완료 거래일 |
| `pred_rank`, `pred_pool_size` | 동일 모집단 내 순위와 유효 종목 수 |

신규 성과 원장에는 점수 유형·모델 ID를 저장합니다. 실제 시가→종가 수익률 집계는 유지하지만 순위 점수를 예상수익률로 표시하거나 부호 적중률로 계산하지 않습니다. 기존 저장 성과 기록을 읽을 때에도 당시 모델 단위를 보존합니다.

## 검증

- 원본 연구에 저장된 2024-12-30, 2025-11-17, 2026-09-29의 전체 193/197/200종목에 대해 원시 출력·최종 점수 대조.
- CPU 원시 출력 허용오차 `atol=2e-5, rtol=2e-4`, 최종 순위 점수 `atol=1e-12`.
- 종목 순서·배치 크기 변경, 동순위, 미래 봉 추가, 거래일 누락, 시장 입력 누락, 가중치 변조, CSV·화면·성과 기록 연결 검사.
- FE: `npm test`, `npm run typecheck`, `npm run build`.

`tests/fixtures/final_rank`는 위 세 날짜의 고정 입력 특징과 이미 저장된 기대 예측입니다. 추론 이식 검사용이며 신규 성능 평가가 아닙니다. 실제 외부 시세·계정·주문 API는 오프라인 테스트에서 호출하지 않습니다.
