# 연속 거래일로 확대한 뉴스 검증 설계

**진행 상태: 중단 (2026-09-26).** 사용자가 가격 단독을 이길 가능성이 낮으면 중지하도록 요청했습니다. 완료된 앞선 실험에서 뉴스 내용의 추가 예측력을 확인하지 못했으므로 확장 수집을 중지했습니다. 마지막 진행 표시는 1,836개 작업 중1,600개였고, 성공한 검색 응답은 로컬 캐시에 보존했습니다. 이 연속 구간의 추가 학습과 성능 평가는 시작하지 않았으며 결과표도 없습니다. 아래 내용은 실행 완료 보고서가 아닌 설계 기록입니다. 완료된 결과는 [앞선 연구 보고서](news_research_conclusion.md)를 참고하세요.

기존 30일은 서로 떨어진 세 구간이며 이후 9월 7일도 짧았습니다. 2026-06-01~09-23의 기존 가격 예측 전체를 사용하고, 빠진 뉴스 날짜를 보충하는 후속 실험입니다. 가격 모델은 그대로입니다. 모든 가격 평가 기간을 이미 살펴봤으므로 독립 최종 test가 아닌 탐색 검증입니다.

## 사전에 정한 시간 분리

- 6월: 첫 학습 자료와 글자 패턴 사전·PCA 학습.
- 7월: 6월로 학습한 후보들을 비교하여 정규화 계수와 뉴스 비중 선택. Rank IC가 가격 단독보다 0.005 이상 개선되지 않으면 뉴스 비중0.
- 8월~9월23일: 선택한 설정을 고정. 매일 전날까지 관측된 결과로 계수만 다시 학습. 8~9월 수익률로 방법·비중을 다시 고르지 않음.
- 고정 기본값(정규화10·뉴스 비중0.25)도 모두 공개. 더 좋아 보이는 기본값 결과를 검증에서 선택된 승자라고 소개하지 않음.

## 비교 방법

공통으로 일별 시장평균 대비 Open→Close 수익률에서 과거 가격 예측이 설명한 부분을 빼고 남은 오차를 학습합니다. 금융 언어모델 전체 미세조정은 하지 않습니다.

| 방법 | 뉴스 입력 | 학습기 | 목적 |
|---|---|---|---|
| 가격 단독 | 없음 | 고정 Huber Ensemble | 기준 |
| 제목 글자 패턴 | 전체 종목 최근 제목 | Ridge | 저비용 문자 기반 기준 |
| 제목 의미 | E5 고정384차원 | Ridge | 일반 뉴스 의미의 추가 정보 |
| 사건 제목 의미 | 실적·계약·법적 문제·자본 관련 제목의 E5 | Ridge | 사건 관련 정보의 선별 효과 |
| 제목 의미 트리 | 6월로 학습한 PCA32차원 + 가격 순위 + 뉴스 유무 | 얕은 boosting | 비선형 결합 |
| 간단한 사건 지표 | 사건 유형별 제목 수 | Ridge | 복잡한 표현이 필요한지 확인 |
| 뉴스 양만 | 기사 개수 | Ridge | 내용 없이 기사 존재·빈도만으로 생긴 효과 |
| 종목 이름만 | 6월에 존재한 종목 ID | Ridge | 의미 모델이 회사 이름을 외운 효과와 비교 |
| 가격 순위 트리 | 뉴스 없음 | 동일 크기의 얕은 boosting | 뉴스 트리의 가격 재보정 효과와 비교 |

사건 제목은 고정 키워드로 선별합니다. 정밀한 사건 확정 여부나 회사 역할을 검증한 라벨이라고 부르지 않습니다. 의미 모델은 최근3일의 최신5개 중복 제거 제목을 합쳐 앞256토큰을 사용합니다. 이번 확장은 제목 연구이며, 가격 후보에 따라 확보한 본문은 사용하지 않습니다.

## 수집과 비용

기존에 확보한 Google News RSS를 재사용하고 6/15~26, 7/13~25, 8/11~9/11을 보충합니다. 일주일 단위 쿼리가100건 상한에 닿으면 한 번 더 기간을 나눕니다. 그래도 상한에 닿은 쿼리는 기록합니다. KOSPI200 기존 가격 패널에서 해당 기간에 등장한 종목을 사용합니다. 시점별 완전한 구성종목 복원으로 주장하지 않습니다.

공개 언어모델은 로컬에서 실행하며 유료 API 비용은 없습니다. 검색 시점은 현재이고 원문 시점 아카이브가 아니므로, 수집을 늘려도 이 한계는 남습니다.

## 평가

8~9월 연속 모의투자는 초기1,000만 원, Top-5, 기존 보유 유지·이탈 종목만 교체, 편도0.125% 비용, 마지막 날 종가 정산입니다. 기존 `portfolio_replay.py`를 그대로 사용합니다. 월별 자금 초기화 결과도 보조적으로 제공하고, 연속 투자와 혼동하지 않습니다. Rank IC, Top-5 Open→Close 수익률, 최종 자산, MDD, 비용, 야간·장중 손익을 함께 기록합니다.

코드: `run_news_continuous.py`, `run_news_continuous_models.py`. 테스트는 현재와 미래 실현값을 제거해도 선형·트리 예측이 같음을 검사합니다.
