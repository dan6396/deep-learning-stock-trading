# 나스닥 → 다음 코스피 참고 통계

팀원의 73.2%는 **코스피 전일 종가→당일 종가** 정의에서 비슷하게 재현되지만, 모델의 **당일 시가→종가** 상승 비율로 사용할 수 없다. 기본 기간의 전일 종가 기준은 73.28%, 시가 기준은 46.56%다. 큰 조건부 평균 등락률도 Yahoo 원자료에서 유사하게 계산되므로, 크다는 이유만으로 산출 오류라고 판단할 근거는 없다.

수치의 원본은 [result.json](result.json)이다. 표는 소수 둘째 자리, 표시 문구는 소수 첫째 자리로 반올림한다. 조회 URL·조회 시각·응답 SHA-256·계산에 사용한 원 일봉(open/close)을 JSON에 함께 저장했으며 외부 패키지 설치 없이 재실행할 수 있다.

## 기간과 원자료 상태

- 기본: **2025-10-22~2026-10-22**, 양끝 포함. 조회된 코스피 245일 중 결측 가격에 관련된 2일을 제외해 243일이다. 실제 유효 관측 마지막 날은 **2026-10-20**이다.
- 3년: **2023-10-22~2026-10-22**, 양끝 포함. 코스피 730일 중 같은 2일 제외, 728일이다. 실제 유효 관측은 2023-10-23~2026-10-20이다.
- 조회 시 Yahoo의 나스닥 **2026-10-21 open/close**, 코스피 **2026-10-21 open/close 및 10-22 close**가 null이었다. query1과 query2에서 같은 결측을 확인했다. 결과 상태는 `partial_missing_prices`이며 완전한 기간 재현이라고 표시하지 않는다.
- 결측 행을 삭제한 뒤 수익률을 계산하지 않는다. 원 날짜를 유지하고, 해당 가격 또는 직전 종가를 필요로 하는 관측을 제외한다. 두 수익률 정의의 비교 표본을 같게 유지하기 위해 공통 완전 관측만 사용한다.
- Yahoo가 원자료를 정정하면 재조회 결과가 달라질 수 있다. 현재 관측값의 고정 재현에는 `--source-json`을 쓴다.

## 정렬과 산식

한국 거래일을 `D`, 미국 현지 거래일을 `U`라고 한다. Yahoo epoch timestamp를 각 시장의 `Asia/Seoul`, `America/New_York` 시간대로 변환한 날짜로 사용한다.

1. 기본 `latest_prior`: `U = max(나스닥 거래일 < D)`. 미국 날짜 기준 `D-1` 이하의 가장 최근 장이다. 월요일 코스피에는 금요일 미국장을 연결하고, 미국 휴장 후에도 최근 장을 연결한다. 한국 휴장 중 미국장이 여러 번 열렸으면 가장 최근 **한 장**만 사용하며 누적 수익률은 계산하지 않는다. 같은 나스닥 장이 여러 한국 거래일에 재사용될 수 있다.
2. 비교 `previous_calendar_day`: `U = D-1`인 관측만 남긴다. 실제 전날 밤 미국장이 열린 날에 해당한다. 월요일은 미국 일요일장이 없으므로 제외된다. 팀원의 “전날 밤 열려 같은 날 새벽 마감” 문장을 문자 그대로 해석하면 이 방식이다.
3. 나스닥 수익률: `r_US = close(U) / close(미국 직전 거래일) - 1`.
4. 코스피 전일 종가 기준: `r_KR_CC = close(D) / close(한국 직전 거래일) - 1`.
5. 코스피 시가 기준: `r_KR_OC = close(D) / open(D) - 1`. `next_session_open_to_close`와 같은 수익률 구간이지만, 지수 통계가 개별 종목 모델 성능을 뜻하지는 않는다.
6. 각 시장 전체 일봉에서 직전 종가를 먼저 구한다. 두 시장의 공통 거래일만 남긴 뒤 `pct_change`하지 않는다. 후자는 휴장 간격의 여러 날 수익률을 일간 수익률로 혼동한다.
7. 수익률 `> 0` 상승, `< 0` 하락, 정확히 `0` 보합이다. 보합은 전체/조건부 비율의 분모에는 남고 4분면 및 방향 일치 분자에는 포함하지 않는다. 시가 기준 보합은 1년 1일, 3년 3일이다.

미국 정규장은 통상 09:30~16:00 ET이며 정상 마감은 한국시간 **다음 날 05:00(서머타임) 또는 06:00(표준시)**다. 조기 폐장일은 더 이르다. 따라서 시각을 항상 06:00으로 고정하지 않는다. 한국 정규장의 일반 시간은 09:00~15:30이다. 날짜 매칭에는 실제 가격이 있는 거래일을 쓰며 특별 개장 시각을 추정하지 않는다. 근거: [Nasdaq 정규장 정의](https://listingcenter.nasdaq.com/assets/RuleBook/Nasdaq/rules/Nasdaq%20Equity%201.html), [KRX 매매거래 시간](https://global.krx.co.kr/contents/GLB/06/0602/0602020204/GLB0602020204T1.jsp).

## 불확실성

연속 관측 **5개**를 한 블록으로 하는 원형 이동 블록 부트스트랩을 **2,000회**, seed **20261023**으로 수행했다. 블록 시작 위치를 균등 복원추출하고 원래 표본 수만큼 이어 붙인다. 각 재표본에서 조건부 비율과 전체 기준선을 **함께 재계산**하여 차이의 2.5/97.5 백분위 구간을 구한다. 기준선 자체가 같은 데이터에서 추정되므로 이를 고정된 이항검정 귀무비율로 취급하지 않는다. CI는 과거 비율 추정의 불확실성이며 미래 수익률 예측구간이 아니다.

팀원의 분면 합계와 비율 계산은 내부적으로 일관된다. 팀원 표만으로도 코스피 전체 상승 기준선은 `130/214 = 60.75%`여서 73.2%를 50%와만 비교하면 상승 조건의 효과를 과장한다.

214일은 지정된 기간에서 어느 연결 방식으로도 재현되지 않았다. 가장 최근 장은 243일, 실제 전날 밤만은 190일이며, 결측 2일로 이 차이를 설명할 수 없다. 원래 분석의 정확한 시작·종료일, 휴장 및 월요일 포함 여부, 날짜 조인 방향, 원자료가 없으므로 원인을 확정할 수 없다. 다른 기간 또는 추가 필터 가능성이 있다.

종가 기준 비율과 평균이 팀원 수치에 가깝다는 사실은 **팀원 통계가 종가 기준일 가능성**을 뒷받침하지만 확정하지는 않는다. 조건부 평균은 상승/하락 부호로 이미 선별된 값이다. +2.62%/-3.40%가 전체 일간 평균이라는 해석 자체가 잘못이다. 1년과 3년 조건부 평균의 차이도 기간 민감도를 보여준다. Yahoo 한 공급자만으로 가격의 정확성까지 확정할 수는 없다.

특히 종가→종가 수익률은 미국장 이후 한국 **시가에 이미 반영된 갭**을 포함한다. 따라서 “나스닥 상승 시 코스피 73% 상승”을 “한국 시가에 매수하면 상승할 비율”로 표시하면 대상 구간이 바뀐다. 시가 기준 결과가 낮아진 정확한 인과 원인은 이 분석으로 식별하지 않는다.

## 실행과 검증

저장소 루트에서 PowerShell/Python으로 실행한다. Python 3.10+ 표준 라이브러리를 사용한다. IANA 시간대 데이터가 없는 Windows Python 환경에서는 `zoneinfo` 오류가 명시되며, 스크립트는 의존성을 자동 설치하지 않는다.

```powershell
python scripts/analysis/nasdaq_kospi_conditional.py --start 2025-10-22 --end 2026-10-22
python scripts/analysis/nasdaq_kospi_conditional.py --source-json materials/reports/macro-nasdaq-kospi/result.json
python -m unittest discover -s tests -p test_nasdaq_kospi_conditional.py -v
```

`--start/--end`는 기본 분석 기간을 지정하고, 3년 비교는 항상 `end`의 3년 전부터 계산한다. 윤년 2월 29일의 3년 전 경계는 2월 28일이다. `--bootstrap`, `--seed`, `--block-length`, `--output`도 지정할 수 있다. 시각상 아직 완료되지 않은 일봉을 피하려고 종료일은 한국시간 오늘보다 이전으로 제한한다.

합성 단위 테스트 8개 통과: 주말·미국 휴장·한국 휴장·미래 정보 차단·각 시장 직전 종가·서머타임/거래소 날짜·보합 분모·결측 비연결·부트스트랩 재현성·네트워크 실패를 확인했다. 실제 Yahoo 조회 성공 후 결측 처리한 결과를 생성했고, 내장 일봉으로 오프라인 재계산했다. 별도의 pandas `merge_asof(allow_exact_matches=False)` 및 `pct_change(fill_method=None)` 계산으로 1년·3년 × 두 정렬 × 두 수익률의 8개 결과를 대조하여 표본 수·4분면 일수·평균·전체 상승 기준선이 모두 일치함을 확인했다. README 권고 문구와 JSON 문자열도 일치한다. 이 작업과 무관한 전체 모델 테스트는 실행하지 않았다.

네트워크/HTTP/잘못된 데이터 실패는 비정상 종료 코드 2와 오류를 반환하고 결과 파일을 덮어쓰지 않는다. 따라서 실패 후 기존 결과가 남아 있으면 그것을 신규 결과로 오인하지 말고 실행 종료 코드와 `generated_at_utc`를 확인해야 한다.

한계: 과거 상관은 인과·예측 보장이 아니며, 거래 비용·슬리피지·개별 종목 적용 가능성을 검증하지 않았다. 휴장 판정은 공급자 일봉의 유무에 의존한다. 날짜 자체가 빠진 공급자 누락과 실제 거래소 휴장은 독립 거래소 달력 없이 구분할 수 없으므로, 이번 결과는 Yahoo 원자료 기반 참고 통계다. 공식 원천 및 다른 공급자와의 교차 검증은 수행하지 않았다.
