# 포스터 문안 초안

이 문서는 제출용 편집 초안이다. 본문은 전개별로 짧게 사용하고 근거·주의는 그림 캡션과 하단 각주로 남긴다. 수치는 저장 실행 당시 값이며 실시간 시세가 아니다. 최종 캡처는 갱신될 수 있다.

## 전체 제목

**KOSPI200 종목 순위 예측과 근거 중심 종합 브리핑**

부제: **20일·120일 Transformer 순위 앙상블에 시장 문맥과 기사 출처를 연결하다.**

제목·모델 구성 근거: [현재 모델 안내](../../../../README.md), [manifest](../../../../models/final_rank_ensemble/manifest.json).

## 전개 1 · 무엇을 적용하려 했나: 주가·매크로·뉴스의 역할 검토

### 포스터 본문

주가 흐름뿐 아니라 해외시장·환율·금리·뉴스를 함께 살펴 종목 선별의 근거를 보여주고자 했다.  
먼저 보조 정보의 관련성을 **모델이 예측하는 다음 거래일 시가→종가 구간**에서 확인했다.  
나스닥 상승 뒤 코스피 상승 비율은 종가→종가 73.3%였지만, 시가→종가는 46.6%로 같은 표본 기준선 50.6%보다 낮았다.[S1]  
추가 매크로 관측과 최신 기사는 순위 가중치에 바로 합치지 않고, 출처와 한계를 읽는 브리핑으로 분리했다.[S1][S2]

### 그림 1 · 수익률 정의를 바꾸면 해석도 달라진다

가로축을 두 구간으로 나눈 비교 막대그래프를 권장한다. 각 구간에는 ‘나스닥 상승 후 코스피 상승일 비율’과 ‘동일 표본 전체 상승일 비율’을 나란히 둔다. 막대에 미래 예측 확률이라는 이름을 붙이지 않는다.

| 비교 구간 | 나스닥 상승 후 코스피 상승 | 동일 표본 상승 기준선 | 근거 |
|---|---:|---:|---|
| 전일 종가→종가 | 73.3% · 96/131일 | 60.9% · 148/243일 | [S1] `close_to_close.metrics` |
| 당일 시가→종가 | 46.6% · 61/131일 | 50.6% · 123/243일 | [S1] `open_to_close.metrics` |

그림 캡션: **한국 시가 갭을 포함한 비율을 시가 이후 상승 비율로 옮길 수 없다.** 요청 기간 `2025-10-22~2026-10-22`, 유효 관측 243일, 마지막 관측 `2026-10-20`, 결측 관련 2일 제외. 직전의 가장 최근 미국장을 연결했다.[S1] 시가→종가 조건부 비율의 95% 구간은 39.9~53.0%이며 기준선과의 차이 구간은 0을 포함한다.[S1] 과거 지수 연관성으로 개별 종목·미래 성능이나 갭 반영의 인과 원인을 입증한 것은 아니다.

### 뉴스 분석 보조 문구

**팀 내부 뉴스 감정분석에서는 다음날 수익률과의 상관이 0.053으로 공유됐다.** 출처: **팀 내부 분석(출처: 팀 공유 자료)**. 이 수치는 위임에 제공된 값이며 저장소에서 기간·표본·산식·원자료를 확인하지 못했다. 독립 재현치와 구분하고, 원자료를 확보하지 못하면 포스터 수치 대신 ‘일관된 추가 예측력을 확인하지 못해 설명 자료로 분리’라는 표현을 사용한다.

저장소 보조 근거: 과거 뉴스 결합 연구도 기사 내용에 의한 일관된 개선을 확인하지 못했다고 보고했다.[S3] 다만 당시 가격 모델·개발 표본의 결과이며 현재 최종 모델과의 직접 비교는 아니다. 낮은 상관 하나로 모든 뉴스 모델이 무효하다고 결론내리지 않는다.

## 전개 2 · Transformer 순위와 여러 근거를 연결한 종합 분석

### 포스터 본문

20일·120일 Transformer가 같은 유효 종목을 비교하고, 기간별 순위 점수를 50:50 단순평균한다.[S4]  
원본 TOP5를 고정한 뒤 시장 관측·종목별 근거와 주의점·관련 기사 출처를 붙인다.[S2]  
Gemini는 입력 사실을 요약하며, 서버가 수치·단위·날짜·인용과 금지 표현을 검사해 실패한 설명만 규칙 기반 문장으로 대체한다.[S2]  
이 결합은 정보를 함께 읽는 구조이며 **예측 성능 향상이나 수익을 입증한 결과가 아니다**.

### 그림 2 · 순위 경로와 설명 경로의 분리

[diagram-system.md](diagram-system.md)의 Mermaid 구성도를 사용한다. 가격·국내 지수 이력 → Transformer → 고정 순위는 실선으로, 시장 관측·RSS 기사 → 설명/검증 → 화면은 점선으로 표현한다. 설명에서 모델로 되돌아가는 화살표를 넣지 않는다.

그림 캡션: **모델은 순위를 산출하고, 브리핑은 그 결과와 관측 자료를 설명한다. LLM은 종목을 다시 선정하지 않는다.** 국내 KOSPI·KOSPI200의 과거 지수 특징은 이미 모델 입력이다. 이번에 분리한 것은 추가 매크로 관측·참고 통계와 최신 기사다.[S2][S4]

모델 선택 각주: 기간별 seed 3개, 총 고정 모델 6개를 사용한다.[S4] 단순평균은 복잡도와 현재 검증 근거를 고려한 선택이다. 개발 구간을 독립 test로 부르거나, 대안별 비교표 없이 최고 성능이라고 쓰지 않는다.[S4]

## 전개 3 · 화면에서 확인하는 분석 과정과 출처

### 포스터 본문

분석 실행 후 종합 브리핑·시장 지표·나스닥 참고 통계·TOP5·종목 상세를 차례로 확인한다.[S2]  
저장된 실행에서 순위 199/199행의 유효성과 연속 순위가 확인됐으며, 브리핑 TOP5의 종목·순서는 원본과 일치했다.[S5]  
별도 설명 생성은 Gemini 실호출 후 9,199ms에 `llm`으로 반환됐다.[S6]  
이 수치는 동작 검증이다. 업종 미확인·수급 출처 불확실·공식 성과 미축적은 화면과 함께 설명한다.[S5][S7]

### 그림 3 · 실제 화면 후보와 캡션

| 컷 | 파일 | 캡션·제출 조건 |
|---|---|---|
| 브리핑·시장·인용 근거 | [브리핑 뷰포트](../screenshots/fe-check/home-1440-dark-viewport.png) | ‘입력 사실을 설명하고 기준 시각·기사 출처를 함께 제공한다.’ 요약 출처·시각은 보존 컷의 실제 상태를 따른다 |
| 전체 작업 흐름 | [최종 전체 화면](../screenshots/fe-check/home-1440-dark-full.png) | ‘고정 TOP5와 근거·주의점을 같은 화면에서 확인한다.’ 포스터에서는 필요한 영역을 크게 배치 |
| 최신 레이아웃 후보 | [fe-check/home-1440-dark-viewport.png](../screenshots/fe-check/home-1440-dark-viewport.png) | ‘조회 상태와 규칙 기반 대체를 표시한다.’ AI 요약 생성 전·야간 미수집·가격 조회 중이므로 Gemini 성공 증거로 쓰지 않음 |
| 상세 패널 | [홈 상세 패널](../screenshots/fe-check/home-1440-dark-viewport.png) | ‘순위 점수·기준일·예측 구간을 시세와 구분한다.’ 전용 리포트의 가격 이력 제공을 증명하는 컷은 아님 |

직접 열어 본 후보들이다. 기사·숫자·미수집 표시를 편집으로 바꾸지 않는다. 전일 코드 정리 캡처는 가상 입력이므로 실제 데이터 동작 컷에 섞지 않는다.[S8] 최종 시연 순서는 [usage-flow.md](usage-flow.md)를 따른다.

## 하단 공통 주의 문구

**순위 점수는 수익률·상승확률이 아닙니다. 시장·기사·LLM 설명은 모델 순위를 바꾸지 않습니다. 과거 통계와 화면 동작 확인은 미래 성과를 보장하지 않습니다.**
