# 데이터 표시와 기록 화면 수정

2026-10-09 실제 로컬 GET 응답에서 모델 전용 완료, 전체 순위 199개, 최종 후보 미생성, 숫자형 상태 갱신 시각을 확인했습니다. 수급 합계 금액과 개별 양수 일수는 있지만 합산 순매수 일수는 없었습니다.

- 모델 전용 완료 시 최종 후보 미생성과 원본 모델 신호 평가를 분리했습니다. 뉴스·수급의 판정 요건은 유지합니다.
- 숫자형 epoch 밀리초 갱신 시각을 지원하고 실행 상태 API에 출처 및 실제 이벤트 기준 시각을 추가했습니다.
- 완료 상태의 오류 부재는 ‘없음’, 생성하지 않은 최종 후보 저장 시각은 ‘해당 없음’으로 표시합니다.
- 실제 자동 수집에 연결되지 않은 성과 ‘수집 중’을 ‘현재 미제공’으로 변경했습니다.
- 키 설정 상태와 실제 외부 접속 확인을 구분해 설명합니다.
- 마지막 실행 카드와 기록 기준 카드 사이에 20px 간격을 추가했습니다.

검증: Vitest 29개 파일 363개 통과, TypeScript/Vite 빌드 통과. model-only-smoke 브라우저 38개 검사 통과, axe WCAG 2.2 AA 위반 및 페이지 넘침 없음. 1440px/375px 기록 카드 간격 확인. 브라우저 검증은 localhost fixture만 사용했으며 Python·유료 뉴스·주문 실행은 없습니다. `report.json`과 PNG 참조.

미구현 항목: 공식/수시 실행 분류, 공식 실행 식별자 발급, 거래일별 실현 성과 수집·집계. 이번 수정은 해당 기능이나 누락된 수급 일수를 만들어내지 않습니다.
