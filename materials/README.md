# 이미지·로그·보고서 자료 모음

이 폴더는 실행 코드가 아닌 보관 자료입니다. 과거 버전의 결과·설명도 포함하므로 최신 모델 성능과 구분해서 읽어야 합니다. 현재 모델·실행법은 [루트 README](../README.md)를 기준으로 합니다.

| 폴더 | 내용 |
|---|---|
| [images](images/) | 화면 캡처, 구조도, 연구 결과 그림 |
| [logs](logs/) | 실행·빌드·검증 로그와 변경 비교 기록 |
| [reports](reports/) | 연구·검증 보고서, 결과표, 보고서에 딸린 데이터 |

각 폴더 아래에는 원래 경로를 유지해 파일 출처와 시도를 추적할 수 있게 했습니다. 옛 학습·실험 실행 코드와 모델 가중치는 이 보관 폴더에도 넣지 않았습니다. 현재 코드의 테스트 입력은 별도로 `tests/fixtures/final_rank`에 있습니다.

정리 내역과 원본 파일 해시는 [organization.json](reports/organization.json)에 기록했습니다. 이미지·로그·숫자 데이터는 내용 변경 없이 이동했습니다. Markdown 문서는 이동 경로에 맞게 링크만 정리했습니다.
