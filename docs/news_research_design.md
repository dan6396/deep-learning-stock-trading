# 가격 예측에 뉴스가 추가 정보를 주는가: 후속 실험 설계

작성일: 2026-09-26. 이 문서는 논문에서 확인한 내용과 이 프로젝트에서 새로 설계한 방법을 구분합니다. 아래 실험은 논문 성능 재현이 아닙니다.

## 이번 실험의 가설과 대조군

1. **뉴스 접근 범위**: 가격 상위 후보에만 한정하지 않고, 기존에 수집한 KOSPI200 전체 검색 결과에서 종목별 최근 3일의 제목을 사용합니다. 새 API 호출은 없습니다. 검색 상한과 검색 누락은 남습니다.
2. **내용 표현**: 제목의 TF-IDF, 본문의 TF-IDF, 제목의 E5 의미 표현, 본문의 E5 의미 표현을 비교합니다. 본문 자료는 과거 후보 정책으로 확보한 일부 종목에만 있으며 9월 본문은 없습니다. 수정판은 각 날짜 원래 수집 계획의 본문만 허용합니다. TF-IDF는 확보된 전문을, E5는 결합 텍스트 앞 256토큰을 사용합니다. E5가 긴 본문 전체를 읽었다고 표현하지 않습니다.
3. **보정 목표**: 고정 Huber Ensemble 순위와 실제 다음 날 Open→Close 수익률 순위의 차이를 학습합니다. 결과는 종목 선택용 점수이며 상승확률/예측수익률이 아닙니다.
4. **가격과 뉴스의 상호작용**: 제목 E5 특징에 가격 순위와의 곱을 추가합니다. 별도 대조군은 기사 내용 없이 뉴스 유무와 가격 순위만 사용합니다. 단순히 뉴스가 있는 대형주를 고르는 효과인지 구분합니다.
5. **뉴스를 사용하지 않을 선택권**: 직전 5개 관측일 검증에서 일평균 Rank IC가 가격 단독보다 0.005 이상 좋아지는 경우만 뉴스 가중치를 채택합니다. 아니면 0입니다. 가격 후보 밖의 종목도 보정 후 Top-5에 진입할 수 있습니다.

## 시간 분리와 평가

- 첫 10거래일은 준비 기간. TF-IDF 사전은 그중 앞 5일에서만 학습하고 고정합니다.
- 이후 매 예측일, 이전 관측일 중 마지막 5일을 내부 검증에 사용합니다. 그보다 앞 날짜로 내부 모델을 학습합니다.
- 정규화 계수 1/10/100, 뉴스 비중 0/0.25/0.5/1을 검증 Rank IC로 선택합니다. 선택 후 예측일 이전 모든 관측일로 다시 학습합니다. 관측일은 연속 달력이 아니며 구간 사이 공백이 있습니다.
- 기본값(계수10·비중0.25) 결과, 각 방법의 검증 선택 결과, 검증에서 방법까지 선택한 결과를 모두 보고합니다. 평가 수익률로 최종 후보를 골라 성공이라고 부르지 않습니다.
- 이전에 살펴본 6~8월 30일과 9월 7일을 재사용하므로 **모든 결과가 탐색 결과**입니다. 현재 9월을 새 독립 holdout으로 부르지 않습니다.
- 기존 엔진으로 구간별 1,000만 원, Top-5, 기존 보유 유지·이탈 종목만 교체, 편도 비용0.125%를 동일 적용합니다. 종료일 종가에 전량 정산합니다. 거래비용 문턱을 수익률 단위가 아닌 순위 점수에 적용하지 않습니다.
- 주요 판단은 Rank IC 개선과 안정성입니다. Top-5 시가→종가 수익률 및 최종 자산·MDD·거래비용도 함께 봅니다. 보유 중 발생한 야간 수익은 Open→Close 예측력과 다르므로 분리 기록합니다.
- 일자 단위 신뢰구간과 종목별 뉴스 보정치를 섞은 대조 실험을 추가합니다. 여러 방법을 반복 시도한 탐색의 한계를 신뢰구간으로 해소했다고 주장하지 않습니다.

## 판단 기준

한 구간에서 돈을 더 벌었거나 한 방법의 평균 Rank IC가 조금 높다는 것만으로 교체하지 않습니다. 날짜별 순위 예측 개선, 기사 내용 없는 대조군 대비 차이, 구간별 일관성을 먼저 확인합니다. 발전 가능성이 있는 후보가 생기더라도 실제 거래 전에 저장한 뉴스로 새로운 기간을 검증해야 최종 채택 근거가 됩니다.

현재 실행 경로는 연구용이며 서비스 기본 Huber Ensemble이나 보유·교체 엔진을 변경하지 않습니다.

후속 실험에서는 과거 데이터로 가격 예측의 기울기를 먼저 보정하고, 가격으로 설명되지 않는 일별 시장평균 대비 Open→Close 수익률만 뉴스로 학습했습니다. 학습 수익률은 ±10%, 뉴스 보정은 ±3%로 고정 제한했습니다. 같은 내부 검증과 투자 엔진을 적용했으며 원 논문의 재현이 아닌 자체 설계입니다. [수정 사항을 포함한 최종 결과](news_research_conclusion.md).
