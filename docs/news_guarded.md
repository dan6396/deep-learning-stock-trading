# 근거 제한 뉴스 보정 실험

기존 Huber Ensemble 예측값은 다음 거래일 시가→종가 수익률 단위로 유지합니다. 새 경로는 LLM에 종목 추천을 요청하지 않습니다. 저장된 본문 분류 결과에서 **종목 직접 관련, 방향이 있는 구체적 기업 사건**만 받아, 가격 예측값에 최대 ±10bp를 더합니다. 근거가 없으면 보정값은 0입니다. 기업 실적·계약·증자·법적 사건·배당·자사주·제품 사건을 사용하며, 사건 유형과 최근 1~3개 달력일의 나이에 따라 미리 정한 감쇠를 적용합니다. 동일 제목의 반복 게재와 매매 결정 시각 뒤에 수정된 것으로 확인된 본문은 제외합니다.

선정 방식은 두 가지를 비교합니다. 매일 점수 상위 5종목을 고르는 방식과, 보유 종목보다 신규 후보의 예상 수익률이 왕복 거래비용 25bp를 초과할 때만 교체하는 방식입니다. 가격 단독과 뉴스 보정에 **똑같은** 두 선정 방식을 각각 적용합니다. 투자 엔진, 매매 시점, 구간별 시작자금 1,000만 원, 편도 0.125% 비용은 동일합니다. 뉴스는 기존 가격 상위 20개와 별도 헤드라인 후보 10개에 대해 이미 확보한 본문 최대 2건을 재사용합니다.

```bash
python -m unittest tests.test_news_guarded -v
python run_news_guarded.py
```

결과는 `outputs/news_guarded_calendar3_v2/report.md`, `equity_comparison.png`, `metrics.csv`, `predictive_metrics.csv`, `verification.json`, 종목별 선정·기사 근거 파일에 남습니다. 재실행 시 입력과 코드 해시가 동결 기록과 달라지면 중단합니다. 추가 API 호출은 없습니다.

이는 **이미 들여다본 30거래일을 재사용한 탐색 실험**입니다. 뉴스 보정을 넣고 매일 상위 5종목을 다시 고르면 세 구간 모두 가격 단독보다 낮았습니다. 비용기준 교체에서는 두 구간 개선, 한 구간 악화였지만, 전체 종목의 일별 Rank IC 평균은 가격 0.0770, 뉴스 0.0769로 실질적인 개선이 없습니다. 수익 변화만으로 뉴스 예측력이 향상됐다고 주장할 수 없습니다.

RSS 검색은 기사를 빠짐없이 확보하지 못하며, 현재 확인한 언론사 본문이 매매 당시의 원문임을 입증하지 못합니다. 뉴스 보정폭과 사건 강도는 과거 뉴스 훈련셋에서 추정한 값이 아니라 고정 휴리스틱입니다. 과거 원문 스냅샷을 확보하고, 학습·검증 기간에서 결합식을 정한 뒤, 아직 보지 않은 미래 구간으로 다시 평가해야 합니다. 이번 코드는 연구용 재실행 경로이며 웹 서비스의 기존 선정 기능을 자동으로 바꾸지 않습니다.
