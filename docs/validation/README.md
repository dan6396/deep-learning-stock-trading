# 고정 모델 이동 및 투자 비교 검증

채택한 `base_huber`, horizon=1, seed 42/43/44 모델을 기본 추론 경로로 옮겼습니다. 재학습하지 않았으며, 원본 체크포인트 SHA-256은 `models/huber_ensemble/manifest.json`에 기록했습니다.

## 가중치 이동

원본에는 주가 인코더와 context MLP가 함께 저장되어 있습니다. 채택한 base 설정은 context 입력을 항상 0으로 만들고 MLP의 두 Linear에는 bias가 없습니다. 이 분기의 출력은 정확히 0이므로 주가 인코더 가중치를 변경 없이 추출했습니다. `conv_proj`는 가중치 호환을 위한 과거 이름이고 실제 구현은 `ChannelLinear`입니다. 모델 안에 Conv1D는 없습니다.

시간 인덱스 0~19, Time2Vec, Linear→GELU, 2층 Transformer Encoder, 시간축 평균, 회귀 head를 사용합니다. 각 출력에 학습 target 표준편차와 평균을 적용한 뒤 세 수익률을 평균냅니다. 세 포트폴리오의 수익률을 평균내는 방식이 아닙니다.

## 오프라인 검사

루트에서 `python verify_ensemble.py`를 실행합니다.

- 14,583개 고정 feature window를 새 코드로 추론해 저장된 예측수익률과 대조합니다. 허용 절대 오차는 `1e-7`, 이동 시 최대 오차는 `8.89e-9`입니다.
- 73일 각각의 Top-5 종목과 순서가 정확히 일치하는지 검사합니다.
- 삼성전자·SK하이닉스의 세 기준일에서 OHLCV→지표→추론을 검사합니다.
- 새 앙상블 순위 및 기존 분류 모델의 고정 순위로 매매 원장을 재생합니다. 매일 현금·평가액·수수료를 독립적으로 대조합니다.
- 불충분하거나 NaN인 입력이 정상 수익률처럼 반환되지 않는지 검사합니다.

자료의 SHA-256은 `tests/fixtures/ensemble/sha256.json`에 있습니다. 참조 예측값은 이동 이전 결과입니다. 기존 모델은 저장된 순위 재생이며 이 명령에서 기존 모델의 전체 추론을 다시 하지 않습니다.
